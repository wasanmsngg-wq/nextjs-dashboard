# v0.2.1 staging patch release

Release date: 2026-08-05

This patch packages the fixes merged after the `v0.2.0` staging tag and closes
the remaining Phase 2 Add-exercise loading backlog. It remains a staging-only
release; public production deployment is deferred until the `v1.0.0` release
review.

## Included changes

- Secure administration pages for users, exercise records, categories, system
  exercises, and customers.
- Shared back navigation and discoverable workout and administration submenus.
- Immediate protected-route transition feedback and corrected language-select
  icon rendering.
- Collapsible, keyboard-accessible sidebar groups that automatically expose the
  active route.
- Immediate Add-exercise loading feedback, disabled form controls during the
  mutation, synchronous duplicate-submit protection, and failure recovery.

## Database and recovery

This patch has no database migrations and does not change stored-data
contracts. The `v0.2.0` migration sequence and staging backup evidence remain
the applicable recovery baseline. Roll forward with a new corrective migration
if a future schema repair is required; never edit an applied migration.

Rollback the application by restoring the previously accepted `v0.2.0` tag in
the isolated staging environment. No database rollback is required for this
patch.
