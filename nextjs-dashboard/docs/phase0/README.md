# Phase 0 product decisions

Phase 0 fixes the MVP boundary before workout and nutrition schemas are added.
The authoritative artifacts are:

- [User stories and acceptance criteria](stories.md)
- [Product, support, privacy, and data decisions](product-decisions.md)
- [Decision log](decision-log.md)
- [Low-fidelity workflows and keyboard notes](workflows.md)
- [Issue and milestone backlog proposal](backlog.md)

These decisions apply to the MVP unless a later issue explicitly changes them
with a privacy, schema, migration, and acceptance-test review.

## Completion record

The product decisions, acceptance criteria, sensitive-field purposes, retention
rules, deletion paths, workflows, and non-goals are documented. Creating the
GitHub milestones and issues remains an external repository action; the proposed
structure is ready in `backlog.md`.
